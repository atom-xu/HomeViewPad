# HomePad 交互修复 03

## 用户场景与范围

1. 音乐中打开 AirPlay 选输出时，维持当前界面与资料，不跳回连接／加载；真正进入后台仍暂停并清理私人内容，恢复和撤权仍重新校验。
2. 第一个时钟／总览页切换前后保持整个视口不透明黑底，不能只剩中间正方形黑色。
3. Home 长按控件的原生菜单预览完整显示图标，保留现有卡片尺寸、布局及图标开关／文字详情行为。
4. Home 已指定摄像头的卡片改用约每十秒更新的静态快照，保留最后一张以避免跨页重复连接闪烁；点开才实时视频，关闭停流。后台／家庭变化／撤权清理缓存并拒绝迟到结果。快照失败必须呈现实际状态，不以演示图顶替。

## 验收

使用独立 iPad 模拟器执行 HomePad scheme XCTest/XCUITest，新增生命周期与摄像头调度／迟到回调测试，检查总览横向切换、长按预览、横屏与最大字号截图。AirPlay 输出／家庭摄像头快照与实时流属于真机硬件验收；合成测试单独标注。完成后更新 VALIDATION 与 INITIALIZATION；不改本轮之外的页面布局、系统旋转、音频路由策略，不提交或推送。

## 状态

四项实现完成并已更新实体 iPad。完整回归 168／170（135 单元全过、33／35 UI），中文音乐用例只补测试就绪等待后，4 条音乐 UI 复测全部通过；跨两次执行 169 个不同方法通过，原有自动城市超时仍保留。完整包导出 70 张截图、查看其中 10 张；复测 7 张均查看。用户已确认音乐 AirPlay 不再跳加载、Home 静态快照能更新，其他硬件路径尚未验收。详情见 [VALIDATION](VALIDATION.md) 与 [完整结果](evidence/ipad-interaction-fixes-full-suite-summary.json)。未提交、推送或发布。
