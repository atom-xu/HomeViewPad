# 音乐浏览与返回 06

## 用户场景与范围

Cover Flow 边缘柔和渐隐；专辑、歌曲、歌单有明确选中区分，歌曲也支持封面翻阅，歌单保持列表。搜索移至顶栏，移除封面下的教学小字、重复“查看专辑”及大随机按钮。播放在浏览原页完成，底部播放栏可打开播放器；播放器仅箭头返回，定位真实播放来源而非当前随意浏览的位置。保留整张专辑／歌单完整队列和重复歌曲位置语义。音乐设置使用原生、不透明、可读的表单。

不改 Home 几何、音频路线、权限范围、后台政策和其他页面。本轮不引入新音乐后端或虚构真实封面。

## 验收

增加来源导航的单元回归，以及渐隐封面、播放留页／返回当前源、歌曲封面、分段选中、歌单列表、设置可读性的 UI 回归。运行 HomePad scheme XCTest／XCUITest，保留失败与最终候选散列并导出检查截图，覆盖横屏两方向、大字号与 Reduce Motion。独立模拟器与有标记的合成音乐不代替真机 Apple Music 验收。

## 结果

应用实现与相关验收已完成；随后已按用户授权安装并启动同一签名包。以下测试与最初连接失败的检查点保留。

- 来源与浏览独立：MusicStore 只在成功代际守卫后记住本次请求的歌曲 ID 列表，getter 再与实际队列比完整多重集合（保留重复计数）。该比较仅是内容兼容检查，不声称严格证明原生队列身份。刷新暂时摘除观察者时也不以旧回读生成新来源。播放失败／取消不确认新来源，失败已替换队列时旧来源不硬套。
- 源专辑／歌单可以重新加载；无来源只在精确歌曲 ID、唯一专辑标题与艺人相符时恢复专辑，否则回真实队列；不以当前随意浏览位置猜来源。
- 专辑与歌曲共享渐隐 Cover Flow，歌单保留列表；只浏览不播放，点播放不强制进入大播放器。歌曲选中从整份资料库的对应索引播放，重复歌单仍按 occurrence 选中。
- 设置使用原生系统 Form；同行刷新／断开明确 plain 样式以隔离点击。UI 回归实际点刷新后检查仍连接／播放／来源，不能只证明可点击。
- 第一次未筛选套件因复审发现刷新指纹时序与表单按钮结构风险，在改源前主动 SIGINT（exit75），当时159单元通过；48文件无漂移。不能把中断当完整通过。以上两个边界在新冻结候选重新验证；第一份构建／测试证据保留。
- Reduce Motion 的代码分支保留；当前未单独注入／观察系统减少动态效果，不称专项验收通过。

未筛选完整 scheme **200／204**（160单元、40／44 UI）。四项失败保留：旧自动城市外部服务超时、摄像头快捷项屏外输入、队列末曲点选，以及总览从控件区域滑动时打开天气。后两项输入失败不能据此断言为黑底渲染或播放源缺陷。新需求明确取消自动跟随定位，以天气07的显式一次请求重新验收；真实逆地理成功仍待验。

合入天气07后的相关 scheme **175／176**（169单元、6／7 UI），摄像头可见新 UUID 菜单及总览背景起点分页均通过，原黑底像素断言保留。末曲准备代码误将940点视口缩为938点，使940点整行不可能完全包含；原始几何与失败保留。修正为真实宽度并等待稳定后，末曲点选及手动城市两条 **2／2** 通过；只改 UI 准备和权限说明的一句中英文，其他45个清单文件不变。末曲断言仍要求九首完整顺序、准确最后歌曲、原队列页面、禁用下一首和返回正确歌曲封面，未放宽。

相关两个结果包合计 **169个单元与8个不同 UI 方法通过**，不是最终单份全绿的未筛选完整套件。截图检查包括柔和边缘、来源 A／B、两方向原生设置、中文最大字号、总览黑边、摄像头可见目标与手动城市。合成音乐有 TEST DATA 标记，不验证真实封面或声学效果。队列额外附件的 app 截图存在方向／裁切问题，改为现有 `XCUIScreen.main` 捕获并单独重复同一验收 **1／1** 通过；完整队列选择前后原始屏幕像素已查看，应用文件不变。精确包、散列和截图检查见 [VALIDATION](VALIDATION.md)与[结果摘要](evidence/ipad-music-browser-weather-summary.json)。
