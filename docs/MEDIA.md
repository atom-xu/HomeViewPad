## Recorded demo

The checked-in GIF is 880 × 606 px, 337 frames at 12.5 fps, 26.96 seconds long, and about 3.2 MiB.

`media/demo.gif` is encoded from a real simulator video, not a sequence of generated UI mockups. It shows the deterministic demo home's thermostat, light controls and widget switching, followed by the clock, photo wall and navigation rail. The Photos library contains original gradient fixtures generated by `scripts/seed_test_photos.py`; no personal photos are included.

The app's normal 30-second album rotation is not accelerated. This short walkthrough demonstrates entering the photo wall; the longer slideshow behavior is covered by the PhotoKit UI test.

To reproduce, use a dedicated, booted iPad simulator with no personal media:

```sh
python3 scripts/seed_test_photos.py SIMULATOR_UUID
python3 scripts/record_demo.py SIMULATOR_UUID
```

The script records between explicit markers in `testReadmeDemoJourney`, ends recording with SIGINT so the movie is finalized, and converts it using AVFoundation and ImageIO. The GIF loops at 12.5 fps with its longest edge bounded to 880 px. Raw recordings and test evidence remain in ignored `.validation/`.
