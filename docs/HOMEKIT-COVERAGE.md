# HomeKit 设备、图标与控制覆盖

更新：2026-10-23，HomeKit控件12。上一版只有9类特征值，现在已扩展为公共SDK服务／类别／特征值驱动的模型，并接入HomeStore和实际界面。[本轮范围](HOMEKIT-CONTROLS-12.md)。

## 图标与类型

以Xcode27公共HomeKit头文件核对：46种服务、33种配件类别全部有明确的SF Symbols映射；锁、门窗、车库门、安防、传感器、电池和媒体另有状态图标。图标只按实际当前状态变化，目标值不能冒充设备已经完成动作。未知、无效或离线读值不会显示成安全／关闭状态。

这是公开设备类型的完整映射，不是Apple家庭内部私有图标包。Apple家庭里用户选定的灯具等外形变体没有公开同步到HomePad；应用不导入其私有资源。厂商未向HomeKit暴露的服务或能力不能凭图标补造。未知服务可按公开配件类别显示只读信息。

## 实际能力

| 类别 | 已接入的状态与控制 | 边界 |
| --- | --- | --- |
| 灯、插座、开关 | 电源、亮度、颜色／色温；图标快切，名称打开详情 | 只显示该服务声明的参数；不把同名设备混在一起 |
| 门锁 | 实际锁定／解锁／卡住状态、明确的锁定与解锁控制；附带电池诊断 | 目标与当前状态分开；仍受HomeKit授权和设备可达性约束 |
| 门、窗、窗帘、百叶、车库门 | 当前开度／移动／障碍，目标开度、开关、停止、支持的倾角 | 停止为请求命令；未回读前不声称物理动作完成 |
| 温控、空调、风扇 | Active／电源、运行状态、冷暖／自动模式、温度阈值、风速、方向、摆风 | 实际枚举选项及设备元数据决定可操作范围 |
| 净化、加湿、除湿 | 工作状态、模式、速度、湿度阈值、水位、滤芯寿命／重置 | 未声明的能力不出现，重置不模拟硬件结果 |
| 安防 | 布防状态、居家／离家／夜间／撤防，实际告警 | 触发告警不是可写目标选项 |
| 人体、存在、门磁、烟雾、水浸、CO／CO₂、空气质量、照度、温湿度 | 对应读数、检测状态及异常强调 | 只读传感器不能被点成开关；事件按钮显示最近事件 |
| 阀门、水龙头、喷灌 | Active、使用状态、时长及剩余时间 | 没有数值范围时不创建自由滑杆 |
| 电视、输入源、扬声器、麦克风 | 公开的电源、播放／暂停／停止、输入源、音量／静音与遥控请求 | iOS18+新增接口有系统版本守卫；输入源取真实关联服务／有效值，不编造列表 |
| 电池、故障、卡住、拆动、滤芯、桥接／路由等信息 | 真实状态与类别图标；辅助诊断关联到同一配件详情 | 管理TLV、密钥／日志和流协商不作为任意可编辑字段 |
| 摄像头／门铃 | 继续在右侧快照／实时视频；公开且可用的相机、音频控制从摄像头详情进入 | 摄像头类别及辅助信息不进入左侧常用；录像回看、对讲和门铃事件通知未实现 |

公共SDK的138个特征常量中，129个有明确的数值、枚举、布尔、事件或只读信息定义；9个二进制管理／流协商项明确排除，由相机系统API处理的视频协商也不做通用编辑。名称、厂商／版本等信息是只读，不意味着实现重命名、自动化编辑或路由器配置。

写权限、有效当前读值、实际有效值集合、最小／最大／步长同时约束控件。服务只形成一张主卡，详情保留其真实关联参数；不同服务和家庭不按名称混合。请求命令无法读取自身状态时只反馈“已发送，等待设备状态”，不会伪造完成。

## 指定HomePod

适合墙上iPad选歌的现有方式：在Home音乐卡、音乐页或音乐设置“播放到”打开系统AirPlay选择器，选择目标HomePod。当前ApplicationMusicPlayer与HomePod独立待播队列是不同能力；本轮没有声称接管HomePod自身的独立队列。HomePod是否暴露其他HomeKit服务以系统实际发现结果为准。
