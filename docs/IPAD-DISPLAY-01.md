# iPad 全屏与展示待机

本轮将 HomePad 调整为适合 iPad 长期放置和日常操作的面板。基于 `3c395111ab2a6c85e62ca763f7c156da4845b49c`，开发分支 `codex/ipad-display-01`。保留初始化文档，不改 HomeKit 写入与回读规则。

后续用户指令覆盖此前竖屏方向：当前只支持左右横屏，保留已有竖屏代码但不再开发。相册壁纸以 aspect-fill 铺满视口，不改首页控件尺寸、排布或独立照片页；取消保留旧图，支持替换、重启恢复和恢复默认。

另一个会话已取得用户对设置精简的明确同意并交接执行：常用设置分为「家庭／显示与待机／内容与隐私／通用」，帮助和关于单列；教程与演示诊断下沉。显示改为三种明确模式，保留旧偏好和独立人脸同意；新安装天气由用户选择城市，默认不申请定位。验收以真实 UI 跳转、模式重启恢复、旧偏好策略测试、原照片/天气面板的取消及隐私边界为准，最终结果见 VALIDATION。

产品方向为 **homepad：iPad 家庭控制与 Standby 常驻面板**。默认进入 Home，设置和自定义组件保持可找回；参见 [同类设计与系统接管边界](IPAD-KIOSK-RESEARCH.md)。

## 系统能力边界

待机是应用在前台的展示状态。应用不调用私有 API，不承诺唤醒系统已锁定或关闭的屏幕。Core Motion 负责移动和姿态检测；相机负责检测画面里有没有人脸，不进行身份识别。接近感应只按设备实际支持情况使用，不能把通用红外当作所有 iPad 都有的能力。

相机、运动服务和亮度管理在离开前台后停止或恢复；权限拒绝和硬件不可用有明确显示。模拟器验证状态转换、界面和设置，真机才能验收感知距离、竖放阈值、耗电、发热及硬件兼容性。

## 视觉验收（用户最终澄清）

用户明确要求复刻第 4 张参考的原有构图，只为 iPad 增加一列。此前“大矩形控制台”和紧凑重排均被用户否定，不再作为设计方向。首页不显示家庭名、房间选择、分区标题、快捷列表或常驻编辑工具栏。

默认主区域保持大温控占 2×2，右侧时钟与摄像头各占一格，下排场景、设备、灯光等大。横屏在右侧新增一列同风格自定义组件。基础格保持同样尺寸的正方形，图标随控件维持同尺寸，大温控保持 2×2。辅助功能大字号保留单列滚动。设备状态与长按增删改尺寸保留，编辑入口收进菜单。独立照片页保留，Home 原图片位置换成摄像头。历史竖屏方案曾采用三列并向底部增加行数；该代码现保留但不启用，不属于当前界面支持范围。

卡片使用系统 Liquid Glass（`glassEffect`，iPadOS 26+），旧系统才用系统 material 回退。用户强调背景色不是本轮重点；不再自绘玻璃、不添加抽象条带、不重做调色。实际截图应确认排布、比例、文字与操作完整；不能用纯逻辑测试代替用户视觉验收。
