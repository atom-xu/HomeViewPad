# Playback and display 05

## 用户场景

墙面常驻 iPad 应能连续播放整个音乐集合及随机播放；播放时封面氛围延伸到 Home 音乐卡和 Home／时钟背景，独立轮播照片页保留原内容。闲置时应在 App 内保护显示，播放音乐也不能永久维持高亮。设置要说明每个选择实际做什么，连接日历后要有清楚的查看路径，天气与权限不能埋在长页底部。

## 范围与产品方向

- 真实 MusicKit 整张专辑／歌单连续播放与整个队列随机播放，检查现有队列为何给人只能播一首的体验。用户确认不做多专辑合并；不把合成资料当硬件成功。
- 音乐实际播放时，当前封面氛围覆盖 Home／时钟页临时背景并进入 Home 音乐卡；暂停／停止后恢复原页面背景，不修改保存的壁纸，不覆盖独立照片轮播或不透明总览黑底。
- 显示模式用简单标题和结果说明：跟随 iPad 自动锁定、保持当前页面、自动进入时钟或照片。App 内保留当前页的闲置调暗与时钟／照片待机分开表达；用户已确认保留当前页并调暗。触摸先恢复、后台恢复亮度；不扩大相机同意或系统解锁能力。
- 设置页面统一完整背景与标题层级；重新梳理“显示与待机”及背景／照片墙用词。日历、天气、内容连接与系统权限提升可达性；连接状态不等同系统权限，不自动申请新授权。
- 保持 Home 控件几何、原生权限与 HomeStore 边界。除本轮目标外的旧定位超时、快速重复预览等保留记录，不顺手扩大。

## 验收与证据

先检查现有实现，以受控单元回归验证队列、随机顺序、取消／撤权和显示状态；新增 UI 检查真实入口、整张播放、队列、背景的页面隔离、闲置恢复、简明设置及中文最大字号。独立合成资料模拟器运行 HomePad scheme XCTest/XCUITest，冻结源码、保留失败与截图，检查实际导出图。实体播放／自动续播／音频／显示验收另记，不以模拟器代替。无 Git 提交、推送或公开发布。

基线快照及后续产物位于 `.validation/local/playback-display-05/`。修改前已检查分支、差异与远端；保留已有未提交工作。

## 实现说明

- 基线 `play(song, from: songs)` 原本就传入整个数组，未把“旧版只播一首”的根因当成已复现。此次明确增加集合入口和真实整队列读回，清除原生播放器继承的单曲循环／随机状态。专辑、歌曲、歌单列表逐页读取；曲目关系继续读取 nextBatch，不停在首个响应。重复曲目保留并按所选位置进入队列。
- 整张／整单随机与当前队列随机均为一次重排动作；当前队列重排包括已播条目，并从新第一首重新播放，不伪装为一个持续开启的模式。多专辑合并不在本次范围。
- 背景只随实际 playing 状态及有效封面显示；没有真实封面时不编造封面。合成截图梯度只在明确标记的 TEST DATA 客户端启用。照片页／总览与本地音频文件保留独立呈现。
- 保持当前页面会在选择的闲置时间后调暗，首次触摸只恢复亮度；明确自动时钟／照片模式按闲置进入，不要求陀螺仪。未知／未选 V1 的旧偏好保持原传感器策略，不自动改用户的摄像头同意。手动预览明确是时钟／照片预览。
- 设置使用同一原生标题与完整背景，新增直接日历／天气单位／权限入口；日历连接成功后可主动添加 Home 日历卡片。权限页面只查询状态，不触发连接或权限弹窗。

首轮诊断构建因 AmbientWallpaper 私有可见性失败，修正后 build-for-testing 通过。首次完整套件尝试因新增 UI 测试使用不存在的 lastMatch 查询未能编译，保留失败记录；仅把查询改为原生元素数组末项后重新冻结运行，不记为已执行测试。最终结果填入 VALIDATION 和交接记录，实体续播／声音仍须分开验证。

UI 闲置首次执行失败已定位为测试设定：NSArgumentDomain 的 `"30"` 是 NSTaggedPointerString，`as? Double` 读取回退到 60 秒；该旅程只等 40 秒，因此未满实际延时。Foundation 独立探针和源码／触摸时间相互印证。保留失败，完整回归结束后仅改测试，使用真实设置 Picker 选 30 秒并断言当前值；不放宽等待、不增加测试专用短计时、不为此改生产偏好读取。

## 最终结果

完整候选 195／198；最终相关 scheme 161／161。最大字号图标重叠经截图发现并用 ScaledMetric 修复；真实 30 秒闲置、首触唤醒、照片轮播与原分页结果均复测通过。最终 48 文件快照 `1c9adfae6796a3460e6e286767d18ddaf46997507e09d003b0426a90e35aa3e6`。完整包查看 10／87 张、最终专项 17／17 张。已更新实体 iPad，用户确认专辑播放有声音且自动进入下一首。旧自动定位超时仍未解决，其他硬件路径不由模拟器或单次专辑反馈代替。[完整验证记录](VALIDATION.md)。
