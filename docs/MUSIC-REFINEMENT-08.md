# 音乐返回与封面、顶部控件 08

## 场景与范围

用户真机反馈：放大播放器选歌后左上返回进入待播清单，待播清单返回播放器，形成循环。新约定是播放器左上箭头及封面点击都回到可选择专辑的封面根页；有明确播放专辑时仅对焦该封面，未知来源也不回队列。队列只由播放器右下清单按钮进入，队列返回播放器后必须仍能退出到专辑卡片。浏览不换队列或播放状态；现有后台／撤权清理与重开空队列保持。

搜索入口和搜索页面撤掉，顶部 AirPlay／音量采用一致44点触控尺寸与图标比例；音量弹层改为清楚的系统滑杆，保留公共 MPVolumeView／AVRoutePickerView 和既有生命周期。Home／背景／照片、实际播放源缓存和设备控制不改。

专辑与歌曲共用 Cover Flow 加四边柔和透明蒙版与上下阴影空间，保留圆角、左右翻阅、单指外侧分页、减少动态效果和大字号列表。

## 验收

先用单元用例记录未知源循环原实现失败；再覆盖已知／未知来源、队列→播放器→封面出口、空队列／专辑、播放留页、整专辑／歌单与重复歌曲、Home联动、跨页恢复。检查搜索移除、音量弹层开关／页面状态及四边渐隐的实际截图，涵盖横屏两方向与最大中文字号。运行 HomePad scheme XCTest／XCUITest，冻结源码与失败记录保留；真机安装、实际视觉／声音／AirPlay另记，合成TEST DATA不作硬件结论。
