# HomePad · 家窗精修

2026-10-16。沿用户选中的第二轮 C「家窗」继续深化：保留三块柔和窗格拼成家的识别，精修几何和材质。配色仍是当前探索基准，用户尚未确认最终颜色或授权替换图标。

| 方案 | 精修重点 | 可用资产 |
| --- | --- | --- |
| C1 · 清 | 干净平面，无渐变或阴影；统一圆角与等宽缝隙。 | [1024 PNG](01-clear/icon-1024.png) · [可编辑 SVG](01-clear/icon.svg) |
| **C2 · 润（推荐）** | 沿用 C1 精修轮廓，增加轻微色阶与很弱的阴影，不加高光边框或塑料效果。 | [1024 PNG](02-soft/icon-1024.png) · [可编辑 SVG](02-soft/icon.svg) |
| C3 · 衡 | 更宽、更低的屋顶，收紧等宽缝隙，探索更稳的几何比例。 | [1024 PNG](03-balanced/icon-1024.png) · [可编辑 SVG](03-balanced/icon.svg) |

推荐 C2：它保留家窗的亲和感，修正原稿的缝宽及圆角节奏，再用克制的层次增加完成度。C1 与 C2 故意保持同轮廓，以便清楚比较平面／层次；C3 则用于比较比例，不把材质和结构混在一起。每个目录还有 120／60 PNG 和可编辑同色 SVG。

## 具体调整

| 项目 | 原 C | C1／C2 | C3 |
| --- | --- | --- | --- |
| 主体宽度 | 512 px／50% | 560 px／54.7% | 584 px／57.0% |
| 屋顶直边坡度 | 约 39.2° | 约 36.9° | 约 33.3° |
| 竖缝／横缝 | 64／40 px | 56／56 px | 48／48 px |
| 主要直角处圆角 | 原二次曲线控制量不同 | 44 px 圆弧 | 48 px 圆弧 |
| 屋脊末端圆角 | 原二次曲线 | 12 px 圆弧 | 14 px 圆弧 |
| 光学位移 | 原位置 | 右移 8、上移 10 px | 右移 8、上移 10 px |

新的圆角由切点与圆弧精确构造，脚本会拒绝相邻倒角重叠。小屋保留略不等分的空间感，三片面板底边对齐；屋顶尖端单独使用较小半径，避免统一半径把轮廓磨钝。原 C 的 SVG 和 1024 PNG 原样保留在 `source/`，不会覆盖第二轮文件。参数、来源散列与范围见 [manifest.json](manifest.json) 和 [BRIEF.md](BRIEF.md)。

## 验证与重建

已查看三套 1024 原稿、原 C 并排、同色结构以及实际 60／120 px 深浅背景预览。九张新 PNG、三张原稿对照 PNG 尺寸和不透明度正确。八项小尺寸检查确认三个窗格完整独立，横竖分隔至少保留 2 个清楚像素；C1／C2 轮廓一致、C3 轮廓不同，平面版不含渐变或阴影。结果见 [validation.json](validation.json)。

环境：macOS 27.0 / arm64，Python 3.13.12、Pillow 12.1.0，Node 22.22.3、Playwright Chromium 135.0.7049.17，1× 像素比。PNG 从 SVG 在目标尺寸直接渲染，全部为全幅不透明正方形。圆角只应用在桌面预览里，不写入原稿。

```sh
python3 design/app-icon/2026-10-homepad-v3/generate.py
node design/app-icon/2026-10-homepad-v3/render.mjs
python3 design/app-icon/2026-10-homepad-v3/validate.py
```

本次图标任务未写入 AppIcon、工程或应用源码；前两轮设计和原 AppIcon 的内容散列保持一致。工作区另有并行功能改动，已保留并单独记录于 `preservation-summary.json`，不能声称整个工作区都未变化。本任务仅设计资产及交接记录改动，未运行 XCTest／XCUITest，未安装模拟器或真机；系统最终遮罩、特殊外观与真机色彩未测。未提交、推送、发布或部署。
