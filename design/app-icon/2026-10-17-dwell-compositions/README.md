# HomePad · 原版家窗的构形探索

2026-10-17。已纠正指代：用户说的“1”是此前最左边的原始家窗，不是后来有编号的 01 暖窗。废弃暖窗作为偏好基底的判断，旧文件保留。

唯一基准：`../2026-10-homepad-v2/03-dwell/icon.svg`，即左高青绿、右上薄荷屋顶、右下暖黄窗块的三块家形。本轮并列基准时明确写“原版家窗”，不编数字；新稿只用 A／B／C。

目标是同一家族里的构形创意：改变三块的组合、负空间、窗与屋顶的关系；不是圆角微调、换色／材质，也不把它改成完整外壳内嵌窗。保持柔和饱满、完整家形与暖窗的识别。当前配色只作比较基准，尚未定稿。

`comparison.png` 为本轮对比图，`index.html` 为离线预览。可编辑 SVG 在 `concepts/`，原版副本在 `source/`，大图审阅副本在 `review/`。本任务只在这个新目录写入设计文件，不修改旧成品、代码或 AppIcon，不提交、推送或安装。

## 审阅与自评

已查看三版 1024 px 大图、原版并排对比以及实际 60 px 小图，三个独立块面和家形均可分清。A 的斜向留白最明显地改变了拼合关系；B 让薄荷屋顶成为右侧空间，暖窗更内聚；C 的横向暖窗更醒目，也比原版增加了暖色视觉重量。三者仍保持左高青绿、薄荷屋顶与暖黄窗块的亲缘。

目前更倾向继续比较 A 的动势与原版的稳定感。B 的内聚感、C 的暖色占比是否符合用户偏好仍不确定，不据此宣布定稿。原版 SVG／PNG 原样保留；原 AppIcon PNG／Contents 散列已核对。

本轮为静态创意预览，未运行应用测试或安装到模拟器／真机，也未检验系统特殊图标外观。实际渲染为 Node 22.22.3、Chromium 135.0.7049.17、1× 像素比。环境正常可执行，无断线阻塞。
