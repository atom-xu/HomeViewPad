HomePad 原创变形

斜面 → 连续弯折的空间边界；中心节点 → 移到入口的小灯。

原标的对称尖角变成有开口的柔和围合。节点离开中轴，让“家”更有生活感。
B · 相连柔和的聚合
VILHIL 正式原标
→
HomePad 原创变形

两条斜面 → 两条弧形连接；独立节点 → 接住它们的共同核心。

从“屋顶”转成三个不等角色的圆润节点。没有五向放射，也不使用空心圆组。
C · 家窗拼合的空间
VILHIL 正式原标
→
HomePad 原创变形

两条斜面 → 屋脊的斜切边；中心矩形 → 一块亮起的小面板。

把原标拆开、扩展成三个不等尺寸的窗格。留白成为连接缝，外缘才显出房屋。
推荐 C · 家窗

它把“家”与“面板”融成一个轻盈轮廓，三个不等尺寸的窗格也更贴近 HomePad 的实际内容。颜色去掉以后，仍然是一个完整、独立的符号。

参考 Home 的空间直觉、SmartThings 的连接语义。不采用它们的具体轮廓、层叠房屋或五向圆环结构。正式 VILHIL 原标另存，未作覆盖。
