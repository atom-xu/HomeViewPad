# HomePad · 回到家窗

2026-10-16。本轮以第二轮原始 03 Dwell 为审美比较基准；它不是被冻结的轮廓，也不是用户已确认的定稿。保留柔和、饱满、完整、简洁、温暖的家居应用感，探索四种不同构形。

重新查看原 Dwell 和八款探索后，对退步的判断：原版以三块有面积主次的饱满面形成完整家形，负空间清楚，暖色窗格面积足够。上一板把块面拆成细框、开口、连接件，家形消失，留白破碎；视觉重量分散，依赖概念文字解释。新方案以完整家形、主次块面与清楚窗口为筛选标准。

场景与范围：iPad 主屏上的 HomePad 独立符号。原 Dwell 保留在旁作基准，新增四个构形；查看大图和 60 px 后交付一张清晰对比图及可编辑 SVG。配色与光感保持接近原版，以便比较结构，不以换色或圆角参数冒充新方向。不复制 Apple / Samsung 图标。

仅在这个新目录创建设计预览与源文件，不改旧成品、AppIcon、工程、功能或其他工作；不安装、提交或推送。不是定稿包装，不逐个制作生产 ZIP。

## 本轮审阅

- 原版与四个新构形在 `comparison.png` 并列，每个都附实际 60 px 图。可编辑源在 `concepts/`，大图审阅副本在 `review/`。
- 首轮审阅淘汰了过尖的直斜切、像积木的独立三角屋顶、仅靠色块分区的假错层，重做为圆润斜向双块面、围合中央暖窗、完整的正面／侧面家形；没有把首轮图直接凑数交付。
- 当前四版在大图及 60 px 下都能直接看成家，轮廓、留白和暖色块仍可分清；没有细框、链条或需要文字解释的抽象结构。未做生产像素或系统图标外观验收。

简短自评：03「同檐」最有继续比较的价值，保留三块面的亲缘，但把空间改为围绕中央暖窗；01「暖窗」最直接。02 更偏图形化，04 更偏具象空间，它们与用户想要的简洁程度是否一致仍不确定。原始 Dwell 的“家＋面板”关系依然清楚，不预设新稿就一定取代原版，也不替用户把本轮建议当成选择。

渲染环境为 macOS 27.0，Node 22.22.3 / Chromium 135.0.7049.17，1× 像素比。本任务未运行应用测试或触碰运行中的应用；只在这个目录写入设计文件，原 AppIcon 及原始 Dwell SVG／PNG 的内容散列已核对。
