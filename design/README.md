# HomePad 设计资料归档

本目录收录 2026-10 的图标探索、选定原稿和展示素材，按用户 2026-10-24 的要求纳入项目历史。各子目录的日期、验收状态和“当轮未提交”说明描述的是制作当时的状态。

- `app-icon/`：历轮方案、可编辑 SVG、预览、生成脚本、来源记录及交付压缩包。当前 App 使用的仍是第二轮原版 Dwell；归档其他方案不等于选用或替换图标。
- `social/`：两轮小红书展示素材、原始参考、编辑源和交付图片。纳入 Git 不等于发布到社交平台。

每套素材保留自己的 README、manifest、来源与验证记录。演示截图、合成测试资料、ImageGen 概念图和真实硬件结果分别标注；历史图片不代表当前版本外观或真实账号／家庭连接已经验收。原图及压缩包按原字节保存。

## 素材权利与用途

代码的 MIT 许可不替第三方素材重新授权。VILHIL 品牌原稿属于用户提供的历史设计参考，不代表 HomePad 改名或使用其私有服务；Apple 官方图片仅作为带来源的比较参考，品牌及媒体权利属于原权利人。Unsplash 摄影按各包 `photo-sources.json` 中的作者、原始页面与许可记录保留。原创设计、AI 概念图及原生 App 截图的生成和变换记录见各自目录。

这些素材不自动进入 App 的资源包，也不改变现有 AppIcon、工程、系统权限或运行行为。重新用于其他发布场景时应沿用对应素材的来源、署名和使用范围。
